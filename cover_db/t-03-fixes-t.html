7#
8# Blocks 1-4 were each confirmed to FAIL against 0.17 (the SimpleFlow-0.17/
9# directory built from the uploaded tarball) before the fix went in. Blocks 1,
10# 3 and 4 use no argument 0.15 did not accept; block 2 needs "timeout", which
11# is 0.16.
12#
13# Blocks 5 and 6 are not regression tests: they cover the corners of the
14# descriptor-level capture that replaced Capture::Tiny in 0.18 -- closed
15# standard descriptors, and the caller's output layers -- where it has to
16# behave as Capture::Tiny did. Both pass against 0.17 as well, which is the
17# point. Block 5 needs "quiet" and "stdin", so 0.17 or later.
18#
19# Blocks 1-3 run task() in a fresh interpreter rather than in this one. The
20# defect there is a forked child escaping into the caller's program;
21# in-process, the escaped copy would be a second copy of this test file,
22# emitting its own TAP. Blocks 5 and 6 do too, because they close or re-layer
23# this process's standard handles.
24#
25# Nothing handed to a child perl as an argument may contain a double quote.
26# On MSWin32 system(LIST) joins its arguments into one command line, wrapping
27# any with a space in double quotes but not escaping the quotes inside, so the
28# child receives a different program: 0.18's blocks 1 and 3 printed no
29# RETURNED line at all on Strawberry Perl 5.42.2. The child code uses qq{}
30# instead, and the command under test, which may itself be quoted, goes
